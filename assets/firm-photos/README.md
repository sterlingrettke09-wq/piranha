# Staged, not served

`assets/` is outside `public/`, so nothing here is built or deployed. These are
consulting-firm photographs fetched 2026-08-19 under written permission from
partners at McKinsey, Bain and BCG.

**The full record — permission text, per-image source page, date, byte count and
the three caveats that came out of fetching them — is in
`public/cities/CREDITS.txt`, Section 2.** It lives there rather than here so that
one file answers "where did every photo in this project come from", including the
ones that are not being used.

The site's actual photos are `public/cities/*.jpg`, all Wikimedia Commons under
an explicit CC licence or public domain. That is Section 1 of the same file.
